## 安装

```sh
curl -fsSL https://raw.githubusercontent.com/mjmichaelware/ATROPOS/main/install.sh | sh
# 或
npm install -g @mjmichaelware/atropos
```

需要 Java 17+。然后：

```sh
cd 你的项目
atropos
```

## 常用命令
