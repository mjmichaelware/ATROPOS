SECTION 5: UX MODAL, HINT, & KEYBINDING MECHANICS

[QUESTION MARK (?) HINT MECHANIC]
TRIGGER: '?' entered at command line.
ACTION: Auto-popups 3-column modal panel (Shortcuts | Commands | General Info). Colors bound to Color_Scheme. Nav: ↑/↓ Navigate, ←/→ Switch View, esc Close.


[SLASH-QUESTION MARK (/? ) CATEGORY HINT MECHANIC]
TRIGGER: '/?' entered at command line.
ACTION: Replaces standard command list with Category Information Mode. Scrolling categories renders scope definitions instead of executing. Nav: ↑/↓ Navigate.


[SLASH (/) CATEGORIZED COMMAND TRIE]
TRIGGER: '/' entered at command line.
ACTION: Opens large, persistent, beautiful command box (responsive to Web/APK/CLI). Tier 1 categories displayed alphabetically. Hovering category renders sub-box with category scope. Arrow Right drills down or opens Tier 4 doc leaf.


[HASHTAG (#) MENTION MECHANIC]
TRIGGER: '#' entered at command line.
ACTION: Pulls files from active CLI root alphabetically. Arrow Down selects. Arrow Right horizontally expands truncated/long file names.


[NUMBER SIGN (#) MACRO KEYBINDING MECHANIC]
TRIGGER: '#<MACRO>' entered at command line (e.g. #ABC).
ACTION: Maps to custom user-defined keyboard shortcut or command alias. Configuration via `/keybinding` to bypass mobile hardware key limitations.

[EXECUTION GATES]

GOVERNED_COMPILE_GATE: Hard exit-code-0 build verification.
CAPABILITY_ATTENUATION_SANDBOX: Disjoint model vs write capabilities ($\text{Cap}(P_\theta) \cap \text{Cap}(A_{write}) = \emptyset$).
REPRODUCIBILITY_CERTIFICATE_ENGINE: SSD byte hashing against authoritative CAS Merkle leaves.


[OMNI-SURFACE UNIFICATION & HARDWARE AGNOSTICISM]
CLI_ENGINE: 4-tier trie taxonomy with ANSI color inheritance.
WEB_COCKPIT: OpenCode-style local terminal-to-browser mirroring via embedded binary WebSocket server (`TerminalMirrorSocketServer` on port 8787).
ANDROID_APK: Direct in-process ART binding via compiled Android Archive (`atropos-core.aar`), linking `AgentService` and `ExecutionPolicyEngine` directly to Jetpack Compose via Kotlin `StateFlow`.
FILESYSTEM_ABSTRACTION: Zero hardcoded absolute paths (`/data/data/com.termux/` eliminated). Native pathing resolved via `System.getProperty("user.home")`, `System.getProperty("java.io.tmpdir")`, and `okio.Path`.
BINARY_DISCOVERY: System executables (`git`, `kotlinc`, `cargo`, `python`) resolved dynamically via `System.getenv("PATH")` scan through `PlatformAdapterRegistry.current().resolveToolPath()`.
