1. Extraction Rules (Locked)
Maximum atomization. Blueprint phases do not consume concrete atoms. Every feature, function, utility, invariant, gate, driver, and
mathematical claim is decomposed until it cannot be divided further.
Hybrid format: Residual Obligation DAG v3 RESEARCH (R:) + IMPL (I:) density combined with HOE Track / dependsOn / WIRE discipline.
Research prompts force external discovery of superior implementations; they never restate Source Doc 7 sketches.
Impl notes name foreseeable failure modes and the cheapest correct path that preserves existing ATROPOS substrate (IsolatedWorktreeService,
VerifiedCompletionGate, BoundedProcessRunner, TerritoryGrant, ArchitectureComplianceChecker, SpecGraphCompiler, DLOI).
Status tags: RESIDUAL | AMENDMENT-CANDIDATE | NEW-SUBSTRATE | 2050-NEURO-SYMBOLIC | SUPERSEDED-CAPABILITY.
WIRE may name classes newly introduced by Source Doc 7. Final section of this document is a mandatory Caller-Completeness Gate that must
pass before any promotion.
Tier discipline: Tier-1 (this document) must reach verified completion before any subsequent tier is scheduled. Tier-1 = total purge of static
templates + live Interface-First Wave factory that produces real applications.


2. Tier Structure
Tier-1 (this DAG): Extirpation of AppSourceTemplate.kt / LanguageScaffold.kt + full Wave 0–4 factory substrate + native toolchains + 2050
neuro-symbolic gates. Acceptance = real applications compile and pass VerifiedCompletionGate with zero template bytes.

Tier-3 (future): Full CLI/Unix sovereignty, PTY process hosting, shell completion engine, OSC-52 clipboard, anti-fake-green oracles at
production scale.
