# Incident Response Runbook

## Incident types

- Application down
- Data integrity issue
- Security incident
- Performance degradation
- Migration failure

## Response steps

1. **Identify**: Determine the scope and impact
2. **Contain**: Roll back the affected component
3. **Assess**: Determine root cause and affected data
4. **Resolve**: Apply fix or restore from backup
5. **Verify**: Confirm resolution
6. **Document**: Record timeline, impact, and resolution

## Communication

- Notify the team via the configured channel
- Update the incident status
- Record all actions taken

## Post-incident

- Root cause analysis
- Fix applied to prevent recurrence
- Runbook updated if gaps found
