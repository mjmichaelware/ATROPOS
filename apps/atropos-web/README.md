# ATROPOS Web
This directory owns the future ATROPOS Human Operating Environment web surface.
It is not a renamed SpecGraph frontend.
## Product Scope
ATROPOS Web owns:
- Home
- Projects
- Work
- Conversations
- Files
- Agents
- Models
- Automation
- History
- Settings
- Developer Tools container
## SpecGraph Integration
The existing SpecGraph web application remains owned by `apps/specgraph-foundry/apps/web/`.
ATROPOS Web may later mount, proxy, link, or compose SpecGraph beneath `/developer/specgraph`.
No SpecGraph compiler semantics shall be copied into this application.
## Current Status
Phase 0 boundary only. No framework or dependency decision is accepted merely by this directory existing.
